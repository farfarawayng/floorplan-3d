# 户型装修设计

纯前端的户型装修设计工具：在 2D 平面图上摆放家具、拆改墙体、测量尺寸，一键切换到 Three.js 3D 场景，可以鸟瞰，也可以第一人称漫游。无需构建；主应用在 `index.html`，图片导入功能由旁边的 JS / CSS 文件提供。

## 上传不同户型图（实验版）

点击顶栏 **上传户型图**，支持 PNG、JPG、WebP（20 MB 以内）。图片在浏览器内处理，不发送到外部识别服务。

1. 宣传单先用 **框选范围** 选出主户型；多户型图也可只圈其中一户。
2. 点击 **识别墙体**。实心深色墙选默认方式，双线线稿可尝试“双线墙”。必要时调整深色阈值、最小墙厚、最短墙段。像素参数对应编辑器底图，最长边缩至 2200 px。
3. 在底图上检查橙色候选：**补墙** 沿墙中心拖动（横竖对齐）；**点选 → 删除** 去除整段；**擦除 / 开口** 框出要擦掉的区域。编辑器内可撤销与重做。
4. 点 **标定** 后，依次点尺寸线的两个端点，输入实际距离（mm），点 **应用尺寸**。没有可靠尺寸时，需勾选“暂估比例预览”；此时尺寸不可当作真实测量结果。不能用建筑面积反推精确比例。
5. 设置墙高，点击 **应用墙体模型**，再切换 **3D 场景**。后续从“文件 → 编辑识别墙体”继续修正。

新图、裁剪或改变比例会替换方案并清空旧布置；主界面撤销可恢复。仅编辑现有同坐标户型的墙段或墙高会保留家具与测量。模型、标定和裁剪底图包含在方案 JSON 与浏览器自动保存中。请导出 JSON 备份；浏览器空间不足时会提示未保存。

### 识别能力与限制

当前使用颜色阈值、连续长条和双线几何提取，**不是训练后的语义分割模型**。适合清晰、横竖墙为主的图纸，输出是需要检查的候选。不同图片使用同一算法，没有针对样例写死坐标。

- 实心墙简图通常更容易处理；彩色售楼图中的柜体、床沿、台面可能被误识别，浅墙和遮挡墙可能漏掉。
- 双线方式可能把衣柜或窗框填成墙；门窗暂不自动分类，开口由用户检查和擦除。不会自动补门窗实体、识别房间或布置家具。
- 不支持斜墙、弧墙、透视纠正、复式楼梯自动建模、PDF/DWG 输入或自动读取尺寸文字。
- 导入墙体结构性质统一为未知，不用于判断能否拆除。
- 矩形参考地面不是房间轮廓，不统计套内面积和地面材料造价。

用户样例人工检查：清晰彩色图、灰墙线稿、简洁实心墙图能提取大部分主体墙；低清彩色渲染图及带家具、阴影的宣传图存在明显误检和漏检。候选数量不是准确率；尚未建立人工墙体标注集，也未验证通用自动还原能力。下一阶段需要在真实标注集上比较语义分割模型的精度与人工修正量，再替换候选提取器。

## 功能

**2D 平面布置**
- 按原始户型 1:60 / 1:100 比例显示，尺寸单位 mm
- 从左侧家具库拖入 60 余种家具家电（卧室、客厅、餐厨、卫浴、家电、书房休闲）
- 拖动移动、旋转（Shift 自由角度）、调整尺寸，贴墙自动吸附
- 测量工具（靠近墙面自动吸附，Shift 锁定水平 / 垂直）
- 拆改非承重墙，承重墙单独标示
- 图层开关：尺寸标注、房间名、家具、网格、承重墙

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间
- 漫游模式：桌面端 WASD + 鼠标，触屏设备用虚拟摇杆，可以点门开关
- 全高墙 / 剖切墙切换，日照时间滑块，夜景灯光
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步

**方案与统计**
- 房间面积与套内使用面积自动统计
- 为每个房间更换地面材料（木地板、地砖、大理石、水磨石、地毯等），按面积加 5% 损耗估算造价
- 撤销 / 重做，方案自动保存在浏览器本地
- 中文 / English 界面切换（顶栏右侧按钮，默认中文，选择会记住）
- 导出 PNG 图片，导出 / 导入方案 JSON

## 快速开始

```bash
git clone <仓库地址>
cd <仓库目录>
```

然后直接用浏览器打开 `index.html`。也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> Three.js 通过 jsDelivr CDN 加载，首次打开 3D 场景需要联网。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D / 3D |
| `V` / `M` / `X` | 选择 / 测量 / 拆改墙体 |
| `R` / `Shift+R` | 选中家具顺时针 / 逆时针旋转 90° |
| `Delete` / `Backspace` | 删除选中家具 |
| `Ctrl/⌘ + D` | 复制选中家具 |
| `Ctrl/⌘ + Z`，`Ctrl/⌘ + Shift + Z` | 撤销，重做 |
| `F` | 适应窗口 |
| `+` / `-` | 放大 / 缩小 |
| `[` / `]` | 展开 / 收起左侧家具库、右侧面板 |
| `Shift + F` | 全屏 |
| `Esc` | 取消当前操作 |
| 漫游：`WASD` / 方向键，`Shift`，`E` | 移动，快走，开关门 |

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 2D 平面图用 SVG 绘制
- 3D 场景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 数据保存在 `localStorage`

## 自定义户型

户型数据写在 `index.html` 里：

- `ROOMS`：房间多边形、名称、默认地面材料
- `WALLS` / `WINS`：墙体与窗洞
- `MATS`：地面材料名称与单价
- `LIB`：家具库（类型、名称、默认尺寸、颜色）
- `buildFurniture()`：各类家具的 3D 模型

改这些数据就能换成自己的户型。
